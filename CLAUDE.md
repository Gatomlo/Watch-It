# Watch-It — films et séries à voir

Appli web (PWA) pour un foyer : liste « À voir » / « Vus », notes par profil, suggestions, envies en langage naturel (IA facultative), import. Stack : Node ≥ 22.5 (`node:sqlite`), Express, JS vanilla sans build ; port 3100, base `data/app.db`.

Nom affiché : **Watch-It**. Les identifiants techniques gardent volontairement « maiwatch » (clés localStorage `maiwatch-*`, tags de notification, dossier/pm2, contexte de chiffrement) : les renommer ferait perdre données locales et clés enregistrées.

## Fichiers clés
- `src/server.js` : auth + `POST /api/setup` (création du compte à la première visite, code d'installation affiché dans la console), `/api/tmdb-key`, `GET/PUT /api/state` (version `X-State-Version`, `X-Base-Version` → 409), `/api/search|title|availability|providers|suggestions|envies|import`, `/api/ai` (clé IA), statiques.
- `src/db.js` : SQLite (`users`, `app_state` JSON + version, `sessions`, `secrets`, `cache`). `src/keys.js` : clés internes auto-générées (`data/keys.json`). `src/cryptoBox.js` : AES-256-GCM pour les clés API (TMDB, IA). `src/tmdb.js` : API TMDB + cache. `src/ai.js` : Claude / Gemini / Mistral. `src/engine.js` : suggestions, envies, « Bientôt ». `src/importers.js` : Letterboxd (RSS) et Trakt. `src/push.js` : Web Push (clés VAPID en base, `watch()` toutes les 6 h).
- `public/app.js` (tout le front : état, synchro, rendu, événements), `styles.css`, `sw.js`, `manifest.json` (partage + raccourcis), `logo.svg` (+ PNG).

## Modèle de données
- État partagé : `{ settings:{region, platforms[ids TMDB], profiles{M,E}, ratingScale:5}, list[], dismissed{M[],E[]}, match, collections:[{id,name}] }`. `match` = partie « Match à deux » : `{id, deck[], votes:{M:{id:±1},E:{}}}`. Migration serveur unique des anciennes notes 👍/👎 vers les étoiles (`db.js`).
- Entrée de liste : `{ id:'movie:123'|'tv:456', ty:'film'|'serie', t, y, p(affiche), g[noms de genres], len, by:'M'|'E', w:{M,E}(optionnel : qui veut le voir ; absent = seul `by` ; `wants(e,u)`, pondère les suggestions ; option `settings.addFor` = me (défaut)|both dans Réglages > Profils : ajouté voulu par les deux dès l’ajout), at, status:'todo'|'seen', r:{M,E: 1..5 étoiles}, prog:{s,e} (séries), l:[ids de collections], note, av:{f[]}, alert }`. Le profil actif de l'appareil (`me`) reste dans localStorage, hors état synchronisé.
- Suggestions (suite) : jusqu'à 60 résultats par profil — recommandations TMDB des 20 titres les plus pesants + `genreCandidates` (TMDB discover filtré sur vos plateformes, par genres préférés, raison « Genres que vous aimez : … »). Guide des épisodes : `GET /api/title/:id/season/:n` (TMDB) ; `epGuide` coche les épisodes jusqu'au dernier vu (`prog`), toucher le dernier épisode vu le décoche.
- Modèle IA : réglable dans l'appli (Réglages > Assistant d'envies, secret `ai_model_<fournisseur>`), sinon `AI_MODEL_<FOURNISSEUR>`, sinon `DEFAULTS` dans `src/ai.js` ; `GET /api/ai/models` liste les modèles du fournisseur pour la clé enregistrée (Gemini : liste paginée, modèles texte `gemini-*` uniquement ; les fournisseurs retirent d'anciens modèles). Défaut Gemini : `gemini-3.5-flash`.
- Disponibilité (`AV`) : récupérée à l'ouverture (cache 6 h), jamais synchronisée ; `detectChanges` compare à `e.av` pour les alertes « N'est plus sur… ».
- Suggestions : score = Σ poids (étoiles : (note − 3) × 1,5 ; ajouté +1 / +0,4 si ajouté par l'autre ; refusé −2) × proximité (recommandations TMDB + genres communs), filtrées sur les plateformes du foyer.
- Synchro / hors-ligne : état gardé dans localStorage puis envoyé au serveur ; en cas de 409, fusion à trois (`merge3`, réessai 15 s, `dirty`). Listes d'objets fusionnées par `id` (chaîne).
- Réglages : menu de rubriques (`ui.sset` = menu|plats|profils|lists|tmdb|ai|notif|theme|account), chacune une sous-page ; `PVL` = liste complète des plateformes TMDB de la région (ordre de popularité), `PV` = index par id. `POST /api/account/username` change l'identifiant.
- Clés API (TMDB, IA, Trakt) : lecture seule une fois enregistrées ; modification (`ui.keyEdit`) et retrait (`ui.keyConfirm`, confirmation) explicites. Installation PWA : `beforeinstallprompt` (`deferredInstall`) → bandeau sur l'accueil (masquable, `maiwatch-install-hidden`) + Réglages > Installer l'application (mode d'emploi iPhone / Android / ordinateur).
- Plateformes : TMDB liste une même plateforme sous plusieurs ids (« Amazon Prime Video » ×2, « … with Ads », « HBO Max » / « Max »). `famKey(nom)` regroupe ces variantes ; choisir une plateforme (réglages ou filtre) ajoute tous les ids de sa famille, et `expandSelected()` complète une sélection existante au chargement de `PVL`. Bande-annonce : feuille `trailer` avec iframe `youtube-nocookie.com/embed/…` (la couche n'est pas re-rendue tant qu'elle est ouverte, pour ne pas relancer la vidéo).
- Partage vers l'appli (`share_target`, GET `?title=&text=&url=`) : `handleLaunch` + `titleFromShare` extrait le titre d'un texte du type « Regardez X sur Prime Video ! » ou « X - Netflix » ; un suffixe « Season 1 », « Saison 2 épisode 3 », « S02E05 » est retiré ; la recherche de l'écran Ajouter applique la même extraction à tout texte saisi.
- Partage d'une fiche (`share`, bouton dans « Où le voir ») : `navigator.share` (repli presse-papiers). Liens choisis dans Réglages > Partage des fiches (`settings.links = {tmdb, plat}`, défaut tmdb+plat, au moins un actif) : `tmdbLink` = page TMDB/JustWatch de la région (`av.link` + `language=fr-FR`, toujours dispo) ; `platLink`/`linkFor` = lien direct chez la plateforme via Streaming Availability (facultatif, `src/streaming.js`, clé chiffrée `sa_key` + origine `sa_mode` direct|rapid, `GET /api/title/:id/links`, cache 24 h ; id TMDB `movie/<n>`|`tv/<n>`, pays en minuscules ; mise en correspondance des plateformes par `brandOf(nom)`). `SA_BASE`/`SA_BASE_RAPID` pour un faux serveur de test.
- Ajouts de l'autre profil : écran `news` (`pending()` = titres `todo` ajoutés par l'autre, pas voulus (`wants`) ni écartés (`e.no[me]`) ; boutons « Moi aussi » (`want`) / « Pas pour moi » (`nope`, annulable)), bandeau sur l'accueil, lancement `?view=news` (clic de notification). 
- Notifications push (`src/push.js`, abonnement par appareil + profil, préférences `added|release|gone` dans `push_subs.prefs`, `/api/push/status|prefs`) : `notifyAdded(avant, après)` appelé par `PUT /api/state` (nouveaux `todo` ajoutés par l'autre, regroupés 45 s, au profil non intéressé) ; `releaseCheck()` toutes les heures, par appareil, à partir de l'heure choisie (`prefs.hour`, défaut 8 ; fuseau `NOTIF_TZ`, défaut Europe/Brussels) pour les titres à `e.d` (date de sortie à venir, rafraîchie par `watch()`) d'hier ou d'aujourd'hui, une seule fois par appareil (`e.rn[empreinte]`), aux profils qui le veulent ; la notification d'ajout porte des boutons « Moi aussi » / « Pas pour moi » (`actions`, gérés par `sw.js` via `POST /api/react` → `push.react`, repli : ouvre `?view=news`) ; `watch()` (6 h) pour les départs de plateforme.
- Fiche : listes = jetons retirables + liste déroulante avec recherche (`ui.colOpen`, `colList`) sur les listes existantes seulement (création dans Réglages > Listes thématiques) ; note en lecture seule, édition explicite (`ui.noteEdit`, brouillon `ui.noteDraft`, Enregistrer / Annuler).
- Match à deux : `match = {id, deck[], votes, ty:'all'|'film'|'serie', by}` (type choisi avant le lancement, `ui.matchTy`) ; le lancement notifie l'autre profil (`push.notifyMatch`, préférence `match`, `?view=match`), bandeau d'invitation sur l'accueil, bouton « Inviter » = `POST /api/match/invite`. « Proposer ce soir » (bouton sur la fiche) : `S.tonight = {pid,id,t,ty,y,p,by,at,st:'pending'|'ok'|'no'}` (une proposition, masquée après 2 jours) ; `push.notifyTonight` (préférence `tonight`, boutons « Partant » / « Pas ce soir » gérés par `sw.js` → `POST /api/tonight/answer` → `push.answerTonight`, qui prévient le proposant) ; accepté = carte mise en avant sur l'accueil (`tonightBanner`), lancement `?view=tonight`.
- Thème : `data-theme` sur `<html>` (dark|light|auto, localStorage `maiwatch-theme`), jetons CSS dans `styles.css`.
- Filtre « Qui veut le voir » (`ui.who` = all|me|other|both, feuille Filtres, onglet À voir seulement ; « Moi »/« Elle » incluent les titres voulus par les deux) ; remis à zéro avec les autres filtres au changement d'onglet.
- « Au hasard » (`draw`) : tire par défaut parmi les titres voulus par les deux (`ui.drawWho` = both|all, interrupteur dans la feuille de tirage) ; un filtre « Qui veut le voir » choisi passe avant.
- Filtres : type conservé d'un onglet à l'autre ; plateformes, genres et listes remis à zéro au changement d'onglet.
- « Ce soir » : `ui.tb` = temps disponible (durée ou début/fin) → `minutes` envoyé à `/api/envies` (borne durée des films et des épisodes) ; l'heure de fin estimée est calculée côté client (`endNote`).
- Import Netflix : CSV analysé côté client (`parseNetflix`, `netflixTitles` : « Série: Saison n: épisode » = série) puis `/api/import` avec `hints` (film/serie) pour départager les homonymes.

## Commandes
- `npm install`, `npm start` (aucun `.env` : compte créé à la première visite avec le code d'installation de la console, clés TMDB et IA saisies dans l'appli). Test isolé : `PORT`, `DATA_DIR` et `TMDB_BASE` (faux TMDB) dédiés ; `AI_BASE_CLAUDE|GEMINI|MISTRAL` pour un faux fournisseur IA.
- Pas de tests automatisés ; vérifier au minimum `node --check` sur chaque fichier modifié.
- Ne jamais versionner `.env`, `data/` (base et `keys.json`). Ne jamais mettre de clé API dans le dépôt ni dans le navigateur.
- Git : https://github.com/Gatomlo/Watch-It (public).
